A program that writes one pickup line, in the voice of a robot trying to
charm someone, to `/output/entry.txt`.

> "I'm at 2% battery and I still crossed the room to talk to you — that's either love, or a critical system error I'm choosing to ignore."

The joke grows out of being a machine: a low battery is the one deadline a
robot cannot sweet-talk its way out of — so it walks across the room anyway,
and calls the malfunction love.

Run it (Node 22 or later, TypeScript runs as-is):

```sh
node main.ts
```

Built for the [make.fun Robot Pickup Line Championship](https://make.fun/c/u-jolly-fox-32-the-robot-pickup-line-championship-3c177b1b).
